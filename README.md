# Nexvia AI & Machine Learning Internship – Final Submission

This repository contains two assigned AI and Machine Learning projects completed as part of the Nexvia internship.

## Project 1: Financial Fraud Detection AI

A machine learning-based system designed to identify potentially fraudulent financial transactions.

**Technologies:** Python, FastAPI, React, Machine Learning, Docker, Kafka and MLflow.

## Project 2: Autonomous Driving AI (ADAS)

An AI-based autonomous driving assistance system using computer vision and object detection techniques.

**Technologies:** Python, YOLO, OpenCV, React, Flask, ByteTrack and MiDaS.

## Repository Structure

- AIML-01_Financial_Fraud_Detection/
- AIML-04_Autonomous_Driving_AI/

Each project folder contains its source code, documentation, architecture diagrams, evaluation reports, screenshots and presentation.
